Peulá

Tema:

Rosh Hashaná & Yom Kippur

peulá dada para o shnat:

2025

Objetivo:

Que nesta época do ano os chanihcim reflitam sobre como as ações deles sobre os outros influenciam neles mesmos

Desenvolvimento:

Os chanichim serão grandes empresários que estão competindo entre si para criar um objeto, para criar este objeto precisarão de recursos, para encontrar estes os chanichim precisarão passar por bases. Os chanichim durante essa corrida por recurso estarão com uma bexiga , que será a vida deles, ou seja, os chanichim só podem passar pelas base se estiverem com uma bexiga, para dificultar o caminho deles haverá um canibal para estourar as bexigas e roubar os recursos que eles conseguirem, para conseguir mais bexigas os chanichim precisarão achar uma base móvel bem escondida que estará com balões, os chanichim também poderão estourar e roubar recursos uns dos outros.
Quando acabar o tempo para conseguir os recursos cada chanichim vai construir seu objeto e tentará vender para os madrichim, só um chanichm ganhará.
Recursos: Papel; canetinha; tinta; cola; tesoura; lã; cartolina; fita crepe....

Sichá:

Como foi a peula? Foi difícil conseguir os recursos? O que vocês fizeram para conseguir os recursos? O que fizeram para conseguir vender seu objeto? Interferiram no que os outros chanichim estavam fazendo ? como se sentiram? Como vocês se sentem quando fazem boas e mas ações? Sugerir que reflitam sobre isso no yom kippur e no rosh hashaná

Parte Técnica:

balões, recurso
