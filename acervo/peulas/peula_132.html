Desenvolvimento:

Polícia e ladrão:
dividir em 2 grupos (policiais e ladrões), um dos policiais é um espião dos ladrões.
O objetivo dos policiais é prender todos os ladrões. Para isso, eles têm que fazer provas para adquirir armar, que dão o "direito" de prender os ladrões.
O objetivo dos ladrões é achar um objeto. Para achar esse objeto eles têm que descobrir quem é o espião, que vai dizer onde está o objeto. Para descobrir quem é o espião, eles vão fazer uma série de provinhas (individualmente). Quando um ladrão fizer todas as provas, ganhará uma senha que irá identificar o espião.
Senha que os ladrões falam: esfiha
senha que o espião responde: babaganush
