Peulá

Tema:

Tikun Hatzmi

peulá dada para o shnat:

2018

Objetivo:

Fazer os chanichim se questionarem a respeito do seu ano
apresentar os conceitos de tikun hatzmi e tikun olam.

Desenvolvimento:

Os chanichim recebem, no começo da peulá, um caderninho. Cada página é um espaço para eles responderem os questionamentos. Cada caderno tem uma numeração diferente para que os chanichim respondam em uma ordem diferente. Na frente de alguma sala terá um mapa, com a numeração das salas. Alguns números podem ser madrichim que fazem os questionamentos.
Cada pergunta faz com que eles respondam de formas diferentes ( escutar música, desenho, escrita, mímica, cruzadinha)

Questionamentos-
1- qual a diferença para os shovavim? Qual a diferença para os amelim? Para os bonim beit?- madrich
2- O que mais motiva na chazit? Pq vcs vem na chazit? Motivação para vir todo sábado?- escrever
3- Peulá que mais gostaram- desenho
4- o que se arrependem no processo- mpimica com madrich
5- característica de madrich que mais se identificam - lista
6- o quanto a kvutzá cresceu, o qua ainda falta para a kvutzá?- fazer uma analogia com animais
7- Qual momento na chazit se sentiram mais parte da kvutzá? Qual momento se sentiram mais parte da kvutzá? - música, com o que acham
8- O que falta para eles serem peilim?- madrich
9- O que eles querem aprender? - cruzadinha
10- O que esperam para os próximos anos? - madrich
11- o que vc aprendeu de judaísmo na chazit? - madrich
12- 5 práticas judaicas que vc faz - desenho
13- motivo individual de R.H e I.K- poema

Sichá:

falar sobre o processo e o momento de reflexão, iom kipur é um momento de reflexão, tikun olam e tikun hatzmi.
